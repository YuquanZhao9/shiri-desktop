# 昱时使用说明

昱时 0.1.1 提供独立的可编辑桌面日历、管理窗口、iPhone 网页版和 iOS 原生工程。当前数据采用本机优先保存，并可通过已经配置的 Supabase 账号同步。更名保留原有本机日程数据目录。

## 账号与忘记密码

- 忘记密码时不要先退出手机或电脑，也不要清除浏览器数据。在登录页填入注册邮箱，点击“忘记密码？发送重置邮件”。
- 打开邮件链接后，手机网页版显示两次新密码输入框；保存后仍是原来的账号 ID，电脑、手机和云端日程不会因为修改密码而删除。
- 如果设备目前仍保持登录，也可在账号区域点击“修改密码”，直接设置新密码。
- 注册已存在的邮箱时，昱时会提示“该邮箱已被注册”，再询问是否发送重置邮件。
- Supabase 只保存密码的 bcrypt 哈希，不能读取或发回旧密码，只能设置新密码。

## Windows 开始使用

1. 双击 [昱时-0.1.1-Windows-输入修复版.exe](./昱时-0.1.1-Windows-输入修复版.exe)。每次打开都默认显示贴齐主显示器工作区四边的桌面日历；旧版保存的“仅管理窗口”模式不会再覆盖这个默认行为。这是未做发行者代码签名的便携版。
2. 桌面日历右上角可选「一周」「两周」「整月」，默认两周。日期行会随着显示周数变高或变矮。单击日期展开小时表；双击日期格就在该格输入标题、日期、时间、重复和备注。点击已有日程也在原格位置编辑，没有侧栏；底层使用可聚焦的无边框输入层来支持 Windows 输入法。没有日期的任务可在管理窗口放入「收集箱」。
3. 在月历中拖动日程可以改日期；在日视图中上下拖动可以调整开始时间。点击日程可精确编辑。
4. 勾选任务表示完成。重复任务只完成当天；修改、拖动或删除会作用于整个重复系列。误删后可在短暂提示中点击「撤销」。

桌面上只显示日历网格和日程，没有清单导航、账号或设置面板。日期格的左键用于选择、双击编辑，右键会转交给 Windows 桌面。点击空白时段或已有日程会在对应日期格内编辑。日历与管理窗口中的修改会互相更新。

按 **Ctrl + Alt + D**、双击系统托盘图标，或点击日历右上角的齿轮，可打开管理窗口，桌面日历继续保留。要暂时收起桌面日历，在管理窗口「设置与同步 → 桌面显示」选择「仅管理窗口」；选择「显示桌面日历」可重新显示。再次双击程序也会回到桌面日历。透明度只影响桌面日历。

当前方案作用于主显示器，保留 Windows 任务栏。日历会浮在桌面图标层之上；格内右键通过 Windows 输入转交给桌面。无法连接桌面宿主时会打开管理窗口并显示原因。真实桌面上的右键、显示桌面与不同屏幕缩放仍需现场验收。

## 提醒与退出

- 在「设置与同步 → 日程提醒」开启提醒，并给日程设置具体开始时间。
- Windows 预排未来 30 天内的提醒。关闭窗口后仍在托盘工作；要完全退出，请右键系统托盘图标并选择退出。
- 退出软件、电脑关机或系统禁用通知时不会准时提醒。全天任务不发送定时提醒。
- 请在「数据备份」中定期导出 JSON。当前数据先保存在本机，不依赖账号。

## iPhone 与同步状态

iPhone 原生工程使用 GitHub 托管的 Mac 编译，无需你自己有 Mac。私有项目地址：[shiri-calendar](https://github.com/YuquanZhao9/shiri-calendar)。Actions 中的「Build iPhone IPA (unsigned)」仅手动运行，产物保留 3 天。

生成的 IPA 还需要个人签名。Windows 可使用 [Sideloadly 官方工具](https://sideloadly.io/)，连接 iPhone 后由你自己输入 Apple 账号完成签名与安装。免费个人签名通常每 7 天续签，未签名 IPA 不能直接在手机上点击安装。本项目不会接收或上传你的 Apple 密码、证书。

后续按已确定的 Supabase 方案注册并配置项目，再启用电脑与手机同步。**本次没有激活云项目，也未完成真实账号的双端同步测试。** 两端启用后需使用同一项目和账号；原来的本机任务通过明确的合并按钮上传。

iPhone 原生版最多预排未来 30 天中最近 60 条提醒，打开应用时更新。网页版不能保证后台提醒。
