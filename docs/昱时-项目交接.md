## 1. 项目目标

“昱时”是一款以 Windows 桌面日历为核心，并计划提供 iPhone 客户端的日历和清单软件。产品参考“日历清单”的使用方式，但界面和实现为本项目独立开发。

已经确认的主要需求如下：

- 月历、待办清单、提醒和重复任务。
- 每天可以展开时间表，以小时为主要单位，并支持半小时安排，交互接近 iPhone 日历的日视图。
- Windows 端启动后默认显示桌面日历。日历附着在 Windows 桌面层，按“显示桌面”后仍应保留。
- 桌面日历铺满主显示器工作区，不在四周留下无意义空白。
- 支持一周、两周和整月三种显示范围；日期格按当前范围自动拉伸，占满可用高度。
- 桌面日历可以直接编辑。双击空白日期格新建日程，点击已有日程进行编辑。
- 编辑界面应出现在对应日期格内，不采用侧栏，也不显示传统独立窗口。为保证中文输入法可用，实际实现使用与日期格重合的无边框顶层焦点层。
- 桌面空白区域及日期格右键应显示 Windows 桌面菜单，不能吞掉系统右键。
- 软件显示名称为“昱时”。为了继续读取已有数据，内部应用标识 `app.shiri.calendar` 和 Windows 本机资料目录名“拾日”暂时保留。
- Windows 与 iPhone 后续使用 Supabase 托管同步。用户没有自建服务器，已接受使用 Supabase，并希望后续协助注册和连接。

### 3.2 最新修复解决的问题

用户在真实 Windows 桌面中双击日期后，中文输入法候选框出现在屏幕左上角，文字没有进入日程标题框。根因不是保存逻辑，而是嵌入 Explorer 桌面层的子窗口不能可靠取得 Windows 输入法焦点。

当前版本保留“表单就在日期格内”的视觉效果，但主进程在对应日期格位置创建一个无边框、无任务栏图标、可取得输入焦点的顶层窗口。保存或取消后，该焦点层关闭，并与桌面日历同步数据。用户不会看到侧栏或传统应用窗口。
