# 昱时 0.1.1 验证记录

## 2026-09-28 格内轻编辑版

- 问题根因：每次双击都新建并加载整个应用窗口（卡顿）；编辑层打开时主进程把桌面日历设为鼠标穿透，但桌面页面缓存的状态未同步，关闭后页面不再请求鼠标，点击全部穿透到 Explorer（点 × 后无法再编辑）。
- 修复：桌面附着后预先加载一个隐藏的格内编辑层并复用；关闭只隐藏，并通知桌面页面重置鼠标状态；页面每秒最多重申一次交互状态作为兜底；请求带序号，迟到的关闭不会隐藏新日期。默认只显示标题与时间，"更多"展开其余字段；回车保存，Esc/× 取消，点别处保存有标题且有改动的草稿。
- `npm test`：18 项 TypeScript 测试、29 项 Node 测试通过（主进程测试覆盖复用、关闭后交还鼠标、Alt+F4 只隐藏、过期关闭被忽略、离开桌面时销毁编辑层）。类型检查与正式构建通过。
- 隐藏 Electron 冒烟测试（隔离 profile）：双击新建并保存；再双击另一日期后点 × 取消，接着双击第三个日期输入并回车保存成功；点已有日程在格内编辑；全程只多一个编辑层窗口。首次创建编辑层约 157ms，复用打开约 43ms（真实运行时首次也已预加载）。
- `昱时-0.1.1-Windows-格内轻编辑版.exe` 为 102036851 字节，SHA-256：`358d2cbdcd72359e2172b99f3cceed79dde60d7c6cd03906783950b08f0d2c0b`；包内 15 个程序与前端文件与源码哈希一致。修改前源码备份在 `源码备份/拾日-2026-09-28-格内编辑修复前/`。
- 未在真实 Explorer 桌面用鼠标验证；需用户现场确认双击速度、点 × 后再编辑、点别处保存和中文输入法。
